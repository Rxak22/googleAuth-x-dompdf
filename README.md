# Google OAuth2 Login with PDF Credential Generator (PHP)

This project is a simple PHP application that implements **Google OAuth2 login** and allows users to generate their login credential information into a **PDF file using Dompdf**.

---

## 🚀 Features

- Google OAuth2 Login
- User authentication via Google account
- Display logged-in user information
- Generate user credential as PDF
- Simple and clean UI design

## ⚙️ Requirements

Before running this project, make sure you have:

- PHP >= 8.0
- Composer installed
- XAMPP / Apache server
- Google Cloud OAuth credentials
